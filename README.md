# Herdr Voice

Русская голосовая диктовка для Windows и macOS. Нажали клавишу, сказали фразу, нажали ещё раз – текст со знаками препинания появился в том поле, где стоит курсор: в мессенджере, браузере, редакторе кода, где угодно.

Распознавание работает полностью на вашем компьютере. Интернет, аккаунты, ключи и подписки не нужны, звук никуда не отправляется.

## Возможности

- **Точное распознавание русского.** Модель GigaAM v3 от Сбера обучена на сотнях тысяч часов русской речи и сама расставляет точки, запятые и заглавные буквы.
- **Быстро и легко.** Фраза распознаётся за доли секунды на обычном процессоре, видеокарта не нужна. Программа занимает около 330 МБ памяти.
- **Длинная диктовка.** Речь распознаётся по ходу записи, на паузах. Минута сплошной речи без пауз тоже обрабатывается целиком, слова не теряются.
- **Незаметность.** Маленький жучок поверх окон не забирает фокус у поля ввода и скрыт от демонстрации экрана, записи и скриншотов.
- **Своя горячая клавиша** и выбор микрофона в меню.

## Как это устроено

```
core/       общий движок: распознавание, определение речи, потоковая диктовка
windows/    приложение для Windows: Tkinter и Windows API
mac/        приложение для macOS: AppKit через PyObjC, установщик
licenses/   лицензии моделей и библиотек
```

| Компонент | Что делает |
|---|---|
| [GigaAM v3 E2E RNN-T](https://github.com/salute-developers/GigaAM) | распознаёт речь, int8, около 220 МБ |
| [onnx-asr](https://github.com/istupakov/onnx-asr) и ONNX Runtime | запускают модель на процессоре |
| [Silero VAD](https://github.com/snakers4/silero-vad) | находит паузы, чтобы распознавать по фразам |
| sounddevice | получает звук с микрофона |

## Приватность

- Звук и текст обрабатываются только в оперативной памяти и не сохраняются на диск.
- Последняя диктовка хранится в памяти до следующей записи или закрытия программы.
- В файле настроек хранятся только положение жучка, микрофон и горячая клавиша.
- Сетевых запросов программа не делает. Интернет нужен только установщику для macOS, чтобы скачать библиотеки и модель.
