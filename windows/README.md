# Herdr Voice для Windows

Русская диктовка в любое поле ввода: Caps Lock – говорите – Caps Lock.

Подходит для Windows 10 версии 2004 и новее и Windows 11, x64. Python, интернет и права администратора не нужны.

## Установка

1. Откройте страницу [Releases](https://github.com/Tenzen1231/Speak-Russian-Herdr-Voicer/releases/latest) и скачайте **HerdrVoice.exe**.
2. Переложите файл в постоянную папку, например `C:\Programs\HerdrVoice`.
3. Запустите его. Модель и все библиотеки уже внутри, первый запуск занимает несколько секунд.

Windows может показать окно «Windows защитила ваш компьютер»: у программы нет платной цифровой подписи. Нажмите **Подробнее → Выполнить в любом случае**. Это нужно сделать один раз.

## Как пользоваться

1. Поставьте курсор в поле, куда нужен текст.
2. Нажмите **Caps Lock** или щёлкните по жучку. Жучок зажмурится и начнёт дёргаться – идёт запись.
3. Говорите. Паузы не мешают: текст распознаётся по ходу.
4. Снова нажмите Caps Lock. Через мгновение текст появится в поле. Enter не нажимается.

Пока программа работает, Caps Lock не переключает регистр. Жучка можно перетащить мышью в любое место экрана.

Если во время распознавания вы переключились на другое окно, текст не потеряется: выберите нужное поле и нажмите Caps Lock ещё раз.

### Что показывает жучок

| Вид | Значит |
|---|---|
| открытые глаза, лёгкое покачивание | ждёт |
| зажмурился, дёргается, красный огонёк | идёт запись |
| бегающие точки снизу | распознаёт |
| зелёная галочка | текст вставлен |
| оранжевый восклицательный знак | что-то пошло не так, причина видна в меню |

## Меню

Меню открывается правым щелчком по жучку.

- **Горячая клавиша включена** – временно отключить перехват клавиши.
- **Выбрать горячую клавишу** – Caps Lock, F8, F9, F10, Pause, Scroll Lock или своё сочетание, например `Ctrl + F9`.
- **Микрофон** – выбор устройства записи.
- **Отменить запись** – выбросить текущую запись.
- **Запускать вместе с Windows** – автозапуск для текущего пользователя. Если переместили EXE, выключите и снова включите этот пункт.
- **Вставить последнюю диктовку** – вставить предыдущий текст ещё раз в другое поле.
- **Закрыть**.

## Демонстрация экрана

Жучок, его меню и окно настройки клавиши не видны при демонстрации экрана в Zoom, Teams, Discord, Telemost и браузере, на записи экрана и на скриншотах. Это работает и при показе всего экрана, и при показе отдельного окна. На вашем мониторе жучок виден как обычно. На панели задач и в Alt+Tab его нет.

## Ограничения

- Вставка в программы, запущенные от имени администратора, может блокироваться Windows.
- Экран блокировки, окно UAC и игры в эксклюзивном полноэкранном режиме перекрывают жучка.
- Нужен процессор x64. Windows на ARM не проверялась.

## Где что лежит

| Путь | Что там |
|---|---|
| `%LOCALAPPDATA%\HerdrVoice\settings.json` | настройки |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\HerdrVoice` | автозапуск |

## Сборка из исходников

Нужен Python 3.14 x64.

```bash
python -m venv venv
venv\Scripts\pip install -r windows\requirements.txt
```

Скачайте файлы модели из [istupakov/gigaam-v3-onnx](https://huggingface.co/istupakov/gigaam-v3-onnx/tree/322c3b29492673eb7d0b434bfa9dfb8653e34d02) в папку `core\gigaam`: `config.json`, `v3_e2e_rnnt.yaml`, `v3_e2e_rnnt_vocab.txt` и три файла `v3_e2e_rnnt_*.int8.onnx`.

```bash
venv\Scripts\python windows\bubble.py                              # запуск без сборки
venv\Scripts\python -m PyInstaller --noconfirm windows\HerdrVoice.spec
venv\Scripts\python -m unittest discover -s core\tests
```

В папке `dist` появятся `HerdrVoice\HerdrVoice.exe` (папка с библиотеками рядом) и `HerdrVoice-Standalone.exe` (один файл).
