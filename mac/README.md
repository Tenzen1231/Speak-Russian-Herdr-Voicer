# Herdr Voice для macOS

Русская диктовка в любое поле ввода: правый Option – говорите – правый Option.

Подходит для macOS 12 Monterey и новее, на Apple Silicon (M1–M4) и Intel. Права администратора не нужны.

## Установка

1. Откройте **Терминал**: нажмите `Cmd + Пробел`, наберите «Терминал» и нажмите `Enter`.
2. Скопируйте команду, вставьте её в Терминал и нажмите `Enter`:

```bash
curl -fsSL https://raw.githubusercontent.com/Tenzen1231/Speak-Russian-Herdr-Voicer/main/mac/install.sh | bash
```

3. Подождите 3–5 минут. Установщик сам скачает Python, библиотеки и модель распознавания (около 1 ГБ трафика), соберёт приложение именно под ваш Mac и запустит его. В конце появится надпись «Готово».

Приложение устанавливается в папку `Программы` вашего пользователя (`~/Applications`) и включается в автозапуск.

## Два разрешения при первом запуске

macOS попросит их сама. Без них программа работать не сможет.

| Разрешение | Где включить | Зачем |
|---|---|---|
| **Микрофон** | нажмите «Разрешить» в окне запроса | слышать вашу речь |
| **Универсальный доступ** | Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включить **HerdrVoice** | горячая клавиша и вставка текста |

После включения универсального доступа перезапускать программу не нужно: через пару секунд клавиша начнёт работать.

## Как пользоваться

1. Поставьте курсор в поле, куда нужен текст.
2. Нажмите и отпустите **правый Option** `⌥`. Жучок зажмурится и начнёт дёргаться – идёт запись.
3. Говорите. Паузы не мешают: текст распознаётся по ходу.
4. Снова нажмите правый Option. Через мгновение текст появится в поле.

Вместо клавиши можно щёлкнуть по жучку. Жучка можно перетащить мышью в любое место экрана.

Правый Option срабатывает только при одиночном нажатии. Сочетания вроде `Option + буква` продолжают работать как обычно.

### Что показывает жучок

| Вид | Значит |
|---|---|
| открытые глаза, лёгкое покачивание | ждёт |
| зажмурился, дёргается, красный огонёк | идёт запись |
| бегающие точки снизу | распознаёт |
| зелёная галочка | текст вставлен |
| оранжевый восклицательный знак | что-то пошло не так, причина видна в меню |

## Меню

Меню открывается по значку микрофона в строке меню сверху справа или правым щелчком по жучку.

- **Начать запись / Остановить и вставить** – то же, что горячая клавиша.
- **Отменить запись** – выбросить текущую запись.
- **Вставить последнюю диктовку** – вставить предыдущий текст ещё раз в другое поле.
- **Горячая клавиша** – правый Option, правый Command, F8, F9 или F10.
- **Микрофон** – выбор устройства записи.
- **Показывать жучка** – можно убрать жучка и пользоваться только клавишей и значком в строке меню.
- **Вставлять через буфер обмена** – запасной способ для программ, которые не принимают обычный ввод. Буфер обмена восстанавливается через полсекунды.
- **Запускать при входе в систему** – автозапуск.
- **Выйти**.

На клавиатурах MacBook клавиши F8–F10 по умолчанию управляют музыкой, поэтому нажимать их нужно вместе с `Fn`.

## Демонстрация экрана

Жучок и его меню помечены для macOS как окна, которые не попадают в демонстрацию экрана, запись и скриншоты. Старые способы захвата это соблюдают. В новых версиях macOS часть программ для звонков может всё равно показывать такие окна, поэтому один раз проверьте в своей программе: включите демонстрацию и попросите собеседника посмотреть.

Если жучок виден, снимите галочку **Показывать жучка**: диктовка продолжит работать по клавише. Оранжевая точка в строке меню во время записи – системный индикатор микрофона macOS, скрыть его нельзя.

## Обновление

Запустите ту же команду установки ещё раз. Модель повторно не скачивается. После обновления macOS снова попросит оба разрешения: так устроена защита для приложений без подписи Apple.

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/Tenzen1231/Speak-Russian-Herdr-Voicer/main/mac/uninstall.sh | bash
```

Удаляет приложение, настройки, автозапуск, кэш модели и выданные разрешения.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Клавиша не реагирует | Проверьте, что HerdrVoice включён в «Универсальном доступе». Если включён, но не работает – выключите, удалите строку кнопкой «−» и запустите программу заново. |
| «Речь не обнаружена» или «Микрофон молчит» | Системные настройки → Конфиденциальность и безопасность → Микрофон → включите HerdrVoice. Проверьте выбранный микрофон в меню. |
| Текст не вставляется в какую-то программу | Включите в меню **Вставлять через буфер обмена**. |
| Жучок пропал | Он мог быть выключен в меню: значок микрофона в строке меню → **Показывать жучка**. |
| Установка прервалась | Запустите команду ещё раз. Если ошибка повторяется, пришлите скриншот Терминала. |
| Рабочий Mac не даёт включить «Универсальный доступ» | Его блокирует политика компании. Нужно обратиться к администратору. |

## Где что лежит

| Путь | Что там |
|---|---|
| `~/Applications/HerdrVoice.app` | приложение |
| `~/Library/Application Support/HerdrVoice/settings.json` | настройки |
| `~/Library/LaunchAgents/com.herdr.voice.plist` | автозапуск |
| `~/Library/Caches/HerdrVoice-model` | кэш модели для переустановки |

## Сборка вручную

Если репозиторий уже скачан, установщик можно запустить из него: `bash mac/install.sh`. Флаги `--no-launch` и `--no-autostart` отключают запуск после установки и автозапуск.
